# GreenThumb 🌱

## What it is
GreenThumb is a plant care web app that helps users track, manage, and improve the health of their plants through personalized care recommendations.

## Features
- Track your plants in one place
- View upcoming care tasks
- Watering reminders
- Simple and clean UI for plant management
- Customizable home screen (in progress)

## How to run it
1. Download or clone this repository
2. Open the project in VS Code
3. Open `index.html` or `scratch.html` in your browser

## Project Structure
- `/html` → main pages (gallery, profile, garden, etc.)
- `/css` → styling files
- `/images` → plant images and assets
- `/src` → logic and data handling
- `script.js` → main frontend logic

## Tech Used
- HTML
